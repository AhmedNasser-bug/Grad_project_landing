## Validation Checklist
1. **Traditional SEO Audit (`OpenSEO` + `claude-seo`)**:
   - Single semantic `<h1>` matching target keyword intent (`line-height: 1.08` to `1.15` per `UI-AESTHETIC-01`).
   - Meta `<title>` (50–60 chars), `<meta name="description">` (140–160 chars), canonical URL, and JSON-LD `MedicalWebPage` / `TechArticle` structured data.
   - Minimum `openseo_score >= 88` and `unlighthouse_seo >= 90`.
2. **Answer Engine Optimization (AEO / GEO)**:
   - Update and validate `llms.txt` so AI answer engines (Perplexity, Google AI Overviews, ChatGPT Search, Claude) index the new Stitch-generated page URL, clinical telemetry benchmarks, and arXiv citations.
   - Verify `robots.txt` allows AI & search crawlers (`GPTBot`, `ClaudeBot`, `PerplexityBot`, `Googlebot`) and declares the sitemap.
3. **Gate Decision**:
   - Insert audit metrics into `validation_audits`. If `gate_passed = 1`, transition `stitch_generated_pages.status` from `DRAFT` to `VALIDATED` and notify `orchestrator`.
