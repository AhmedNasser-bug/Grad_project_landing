# Sequence / Flow Diagram

> Generated by Graphify on 2026-08-11. Page Initialization, Persona Routing, and WebGL Lifecycle Sequence.

## Diagram

```mermaid
sequenceDiagram
  actor User
  participant Browser as Browser Client
  participant Nav as PersonaToggleNavbar.astro
  participant Router as UTMRouter.ts
  participant Store as localStorage
  participant Canvas as WebGL Canvas Engine

  User->>Browser: Navigate to Portal URL (?utm_persona=nurse)
  Browser->>Nav: Render Navbar Component
  Nav->>Router: UTMRouter.init()
  Router->>Store: Read stored persona

  alt Query Parameter Present
    Router->>Router: Extract 'nurse' from URL
    Router->>Store: Write 'nurse' to localStorage
  else No Query Param
    Router->>Router: Use stored or default 'clinician'
  end

  Router->>Nav: Apply active tab highlighting
  Nav->>Browser: Update Header Pill & Persona Badges

  Browser->>Canvas: Initialize CadWireframeEngine & FluidShaderEngine
  Canvas->>Canvas: Start requestAnimationFrame loop (60 FPS)

  alt User switches Persona to 'Patient'
    User->>Nav: Click 'Patient' Tab
    Nav->>Router: UTMRouter.setPersona('patient')
    Router->>Store: Write 'patient' to localStorage
    Router->>Browser: Dispatch CustomEvent('utm_persona_changed')
    Browser->>Nav: Update Active Tab & Badge Text
  end

  alt User navigates away / page unmount
    Browser->>Canvas: Trigger Astro Page Swap / Unmount
    Canvas->>Canvas: engine.destroy() [cancelAnimationFrame, dispose WebGL]
  end
```

## Analysis Notes

- **Initial Load Sequence:** Seamlessly resolves priority between URL parameters (`?utm_persona=`), `localStorage`, and default fallbacks.
- **Dynamic Event Bus:** UI components react to window custom events without requiring full page refreshes.
- **Clean Unmount Sequence:** WebGL animation frame loops and buffers are freed prior to route transitions.
