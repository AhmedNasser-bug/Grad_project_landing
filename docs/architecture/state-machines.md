# State Machine Diagram

> Generated by Graphify on 2026-08-11. State transitions for UTMRouter and WebGL Engine Lifecycles.

## Diagram

```mermaid
stateDiagram-v2
  state "UTMRouter Lifecycle" as UTM {
    [*] --> Uninitialized
    Uninitialized --> Hydrating : DOMContentLoaded / Page Load
    Hydrating --> ClinicianMode : ?utm_persona=clinician
    Hydrating --> NurseMode : ?utm_persona=nurse
    Hydrating --> PatientMode : ?utm_persona=patient
    Hydrating --> ClinicianMode : Default / Invalid Parameter

    ClinicianMode --> NurseMode : Tab Click / URL Change
    ClinicianMode --> PatientMode : Tab Click / URL Change
    NurseMode --> ClinicianMode : Tab Click / URL Change
    NurseMode --> PatientMode : Tab Click / URL Change
    PatientMode --> ClinicianMode : Tab Click / URL Change
    PatientMode --> NurseMode : Tab Click / URL Change
  }

  state "WebGL Engine Lifecycle (CadWireframeEngine / FluidShaderEngine)" as WebGL {
    [*] --> Standby
    Standby --> Initializing : Constructor(container, options)
    Initializing --> ActiveRendering : Setup Geometries + Start Render Loop
    ActiveRendering --> ContextSuspended : webglcontextlost event
    ContextSuspended --> ActiveRendering : webglcontextrestored event
    ActiveRendering --> Destroyed : engine.destroy() / Astro Page Unmount
    ContextSuspended --> Destroyed : engine.destroy()
    Destroyed --> [*]

    note right of Destroyed
      Enforces WAF COST-01:
      1. cancelAnimationFrame
      2. geometry.dispose()
      3. material.dispose()
      4. removeEventListener
    end note
  }
```

## Analysis Notes

- **Persona Routing Finite Automaton:** Guarantees deterministic state between `clinician`, `nurse`, and `patient` modes.
- **Resource Teardown Automaton:** Complies with WAF `COST-01` memory safety. On page transition or engine unmount, all WebGL buffers, geometries, materials, and RAF timers are explicitly disposed.
